# 🌐 Personal Portfolio Website

This is my personal portfolio website designed and developed to showcase my
skills, education, experience, and contact details in a clean and professional
way.

The portfolio is fully responsive and optimized for both desktop and mobile
devices.

## 🛠️ Technologies Used

- **HTML5** – Semantic and structured markup  
- **CSS3** – Modern layouts, animations, gradients, responsive design  
- **JavaScript** – Basic interactivity and behavior  
- **Git & GitHub** – Version control and source code management  
- **Netlify** – Hosting and deployment  

---

## ✨ Features

- Responsive navigation bar
- Hero section with introduction
- About section with animated profile image
- Skills section with technology cards
- Education and experience sections
- Contact details with email, phone, and LinkedIn
- Clean UI with modern dark theme
- Mobile-friendly design
