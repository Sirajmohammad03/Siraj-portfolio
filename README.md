A responsive personal portfolio website built using HTML, CSS, and JavaScript.

This portfolio showcases my skills, education, experience, and projects, and is designed
to be clean, modern, and mobile-friendly.

🔗 Live Demo: https://siraj-mohammad-portfolio.netlify.app/

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript
- Git & GitHub
- Netlify (Deployment)

## Features
- Responsive design (mobile & desktop)
- Animated hero section
- Skills, education, experience sections
- Resume download
- Deployed live on Netlify
